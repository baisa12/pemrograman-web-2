# Pemrograman Web 2 - Pertemuan 1

Folder ini berisi pengerjaan seluruh latihan pada materi **Pengenalan PHP**:

1. `latihan1.php` - perbedaan variabel lokal dan global.
2. `latihan2.php` - penggunaan kata kunci `global`.
3. `latihan3.php` - konstanta dan perhitungan luas lingkaran.
4. `latihan4.php` - penyisipan PHP ke dalam HTML, komentar, variabel, perkalian, dan fungsi `pow()`.

## Menjalankan

Simpan folder ini di dalam `htdocs` XAMPP, nyalakan Apache, lalu buka:

```text
http://localhost/pertemuan%201/
```

Halaman `index.php` menyediakan tautan menuju setiap latihan.
