# Pemrograman Web 2 - Pertemuan 9

Folder ini berisi pengerjaan materi **Function Lanjutan**. Penomoran latihan meneruskan Pertemuan 8:

1. `latihan4.php` - menampilkan tanggal dan jam server menggunakan `date()`.
2. `latihan5.php` - mengambil array informasi waktu menggunakan `getdate()` dan menentukan salam berdasarkan jam.

Kedua latihan menggunakan zona waktu `Asia/Jakarta`. Materi tambahan pada slide membahas fungsi string (`strlen`, `strtoupper`, `substr`, `str_replace`, dan lainnya) serta pemanggilan file dengan `require()` dan `include()`.

## Menjalankan

Nyalakan Apache XAMPP, kemudian buka:

```text
http://localhost/pemrograman%20web%202/pertemuan%209/
```

Folder ini tidak menggunakan database.
