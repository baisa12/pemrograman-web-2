# Pemrograman Web 2 - Pertemuan 4

Folder ini berisi pengerjaan materi **Struktur Kontrol Lanjutan**:

1. `latihan1.php` - tabel harga kuas menggunakan `while`.
2. `latihan2.php` - pencacahan nilai 0 sampai 9 menggunakan `do...while`.
3. `latihan3.php` - menampilkan bilangan 1 sampai 24 menggunakan `for`.
4. `latihan4.php` - menampilkan bilangan ganjil menggunakan `continue` serta menjelaskan perbedaan `break` dan `continue`.
5. `latihan5.php` - menampilkan elemen array hari menggunakan `foreach`.
6. `latihan6.php` - tugas lanjutan berupa tabel perkalian 1 sampai 10 dengan perulangan bersarang.

## Menjalankan

Nyalakan Apache XAMPP, kemudian buka:

```text
http://localhost/pemrograman%20web%202/pertemuan%204/
```

Folder ini tidak menggunakan database.
