# Pemrograman Web 2 - Pertemuan 3

Folder ini berisi pengerjaan empat latihan pada materi **Struktur Kontrol PHP**:

1. `latihan1.php` - memilih kotak berdasarkan warna bola dengan `if...elseif...else`.
2. `latihan2.php` - menentukan diskon dan pembayaran berdasarkan besar pembelian.
3. `latihan3.php` - menentukan persiapan perjalanan dengan `switch case`.
4. `latihan4.php` - menampilkan agenda berdasarkan nama hari dengan `switch case`.

`index.php` menjadi halaman utama untuk membuka semua latihan. Tampilan bersama disimpan di `style.css`.

Contoh dari slide telah disesuaikan agar berjalan baik pada PHP 8.2. Penyesuaian tersebut meliputi penggunaan `$_GET`/`$_POST`, inisialisasi variabel sebelum dipakai, validasi input, serta perbaikan penulisan nama hari `Thursday`.

## Menjalankan dengan XAMPP

Nyalakan Apache melalui XAMPP Control Panel, kemudian buka:

```text
http://localhost/pemrograman%20web%202/pertemuan%203/
```

Folder ini tidak menggunakan database.
