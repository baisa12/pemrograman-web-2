# Pemrograman Web 2 - Pertemuan 6

Folder ini berisi pengerjaan materi **Array**:

1. `latihan1.php` - menghitung elemen array numerik dan asosiatif menggunakan `count()` serta `sizeof()`.
2. `latihan2.php` - menampilkan setiap elemen array menggunakan `foreach`.
3. `latihan3.php` - menampilkan nama dan usia karyawan dari array asosiatif.

## Menjalankan

Nyalakan Apache XAMPP, kemudian buka:

```text
http://localhost/pemrograman%20web%202/pertemuan%206/
```

Folder ini tidak menggunakan database.
