# Pemrograman Web 2 - Pertemuan 2

Folder ini berisi pengerjaan tiga latihan pada materi **Elemen-Elemen Dasar PHP**:

1. `latihan1.php` - operator penggabungan string dan operator aritmetika.
2. `latihan2.php` - perhitungan pemesanan peralatan kantor, diskon, dan total pembayaran.
3. `latihan3.php` - kalkulator sederhana dengan operator tambah, kurang, kali, dan bagi.

`index.php` menjadi halaman utama untuk membuka semua latihan. Tampilan bersama disimpan di `style.css`.

## Menjalankan dengan XAMPP

XAMPP bukan persyaratan khusus dari PPT, tetapi dapat digunakan karena menyediakan Apache dan PHP. Salin folder `pertemuan 2` ke dalam folder `htdocs`, nyalakan Apache, kemudian buka:

```text
http://localhost/pertemuan%202/
```

Latihan pada pertemuan ini belum menggunakan database, sehingga SSMS maupun MySQL tidak diperlukan.
