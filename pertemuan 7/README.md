# Pemrograman Web 2 - Pertemuan 7

Folder ini berisi pengerjaan materi **Array Lanjutan**. Penomoran file mengikuti nomor latihan pada slide:

1. `latihan4.php` - memeriksa tipe variabel menggunakan `is_array()`.
2. `latihan5.php` - memindahkan elemen array ke variabel terpisah menggunakan `list()`.
3. `latihan8.php` - menggabungkan elemen array menggunakan `join()`.
4. `latihan9.php` - mencari nilai array menggunakan `in_array()`.
5. `latihan10.php` - mencari nilai dan tipe data menggunakan mode strict pada `in_array()`.

Materi juga menjelaskan `split()`. Fungsi tersebut sudah dihapus dari PHP modern; penggantinya adalah `explode()` untuk pemisah berupa string atau `preg_split()` untuk pola regular expression.

## Menjalankan

Nyalakan Apache XAMPP, kemudian buka:

```text
http://localhost/pemrograman%20web%202/pertemuan%207/
```

Folder ini tidak menggunakan database.
