# Pemrograman Web 2 - Pertemuan 8

Folder ini berisi pengerjaan materi **Function**:

1. `latihan1.php` - function sederhana yang menerima parameter.
2. `latihan2.php` - function penjumlahan, pengurangan, perkalian, dan pembagian.
3. `latihan3.php` - function dengan parameter jumlah pengulangan bernilai default.

Contoh pada materi telah disesuaikan dengan PHP 8.2, termasuk penggunaan `$_POST`, validasi input, pemanggilan function tanpa sintaks referensi lama, dan penanganan pembagian dengan nol.

## Menjalankan

Nyalakan Apache XAMPP, kemudian buka:

```text
http://localhost/pemrograman%20web%202/pertemuan%208/
```

Folder ini tidak menggunakan database.
